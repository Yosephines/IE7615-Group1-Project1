# Milestone 1 report

**Start with [proposal_and_training_results.pdf](proposal_and_training_results.pdf).** It combines the team's proposal and the training results, including the charts.

The separate files are retained for submission:

- [Proposal](group_01_proposal_v1.pdf): the team's uploaded cover page and one-page proposal.
- [Training results](group1_training_results.pdf): three pages of methods, results and charts.

The combined file preserves both documents. To update it after either changes, run `python project/scripts/combine_reports.py` from the repository root.
